# 企业项目资源与费用管理系统
# V1.0 Pilot 第一小批真实数据导入与验收执行文档

版本：V1.0 Pilot Batch 1
前置状态：Pilot Environment READY
目标：使用少量真实业务数据完整验证“人员 → 项目 → 成员 → 资源 → 分配 → 费用 → 统计 → 导出 → 提醒 → 审计”真实链路。

---

## 一、本批次目标

本批次不是“全量上线”。

只验证：

```text
真实人员
↓
真实项目
↓
真实项目成员
↓
真实资源类型
↓
真实资源账号
↓
真实资源分配
↓
真实费用
↓
真实系统账号
↓
四角色权限
↓
Dashboard
↓
Export
↓
Reminder
↓
Audit
```

通过后再扩大真实数据量。

---

## 二、建议第一批真实数据规模

建议：

```text
Employees: 5–10
Projects: 2
Project Members: 5–10 条关系
Resource Types: 3–5
Resources: 5–10
Resource Allocations: 5–15
Expense Types: 3–5
Expenses: 10–30
```

系统账号：

```text
ADMIN: 1
BOSS: 1
PROJECT_MANAGER: 2
MEMBER: 2–3
```

---

## 三、两个项目选择原则

优先选：

```text
Project A：
数据完整、负责人明确、资源较多

Project B：
人数较少，但能形成另一个 Scope 边界
```

这样可以验证：

```text
PM-A 看不到 Project B
PM-B 看不到 Project A
Member-A 看不到其他项目
Boss 全局只读
Admin 全局读写
```

---

## 四、第一批资源建议

至少覆盖：

```text
1 个 AI 工具
1 个开发工具
1 个服务器 / 云资源
1 个共享账号
1 个即将到期资源
```

例如：

```text
Cursor
ChatGPT
GitHub
云服务器
API Account
```

至少包含：

```text
单人资源
多人共享资源
项目级资源
项目+成员资源
```

---

## 五、第一批费用建议

至少覆盖：

```text
周期订阅
一次性费用
API Usage
服务器费用
```

建议：

```text
10–30 条近期费用
```

至少包含：

```text
CNY
USD（如果真实业务存在）
```

如果真实业务当前没有 USD：

不要为了测试强行造 USD。

多币种能力已在自动测试和 Gate 5 验证中通过。

---

## 七、每次 Import 必须遵循

```text
下载模板
↓
填写真实数据
↓
Preview
↓
errors = 0
↓
人工核对 Preview
↓
Commit
↓
数据库 / 页面抽查
```

禁止：

```text
Preview 有错误仍 Commit
直接调用 Commit 绕过 Preview
```

---

## 八、Employees 批次

字段必须核对：

```text
employee_no
name
department
position
email
phone
employment_status
```

要求：

```text
employee_no 唯一
ACTIVE / INACTIVE / LEFT 合法
邮箱格式正确
无 password 列
```

Commit 后核对：

```text
页面数量
数据库数量
重复工号
人员状态
```

---

## 九、Projects 批次

至少导入：

```text
Project A
Project B
```

字段：

```text
project_code
name
manager_employee_no
status
start_date
end_date
description
```

负责人必须已经存在于 Employees。

Commit 后核对：

```text
负责人正确
状态正确
项目数正确
```

---

## 十、ProjectMembers 批次

要求：

```text
Project 存在
Employee 存在
active membership 正确
```

必须覆盖：

```text
一个成员同时参与两个项目（如果真实情况存在）
```

没有真实跨项目成员时，不造假。

```text

```

```text
SUM(distributions) == amount
```

## 十八、PM 验收

```text

不能看到 Project B
```

---

## 十九、MEMBER 验收

确认：

```text
只看到参与项目
只看到直接分配资源
只看到直接费用分摊
不能看到同项目其他成员资源
不能看到项目公共费用
不能看到公司总费用
```

---

## 二十、Dashboard 验收

确认：

```text
ADMIN / BOSS = 全局
PM = 自己项目

```

禁止：

```text
假数据
Scope 越权
CNY / USD 混合总额
```

## 二十二、Reminder 验收

建议第一批真实资源中至少有：

```text

```

验证：

```text
ADMIN/BOSS 看得到
对应 PM 按项目看到
Member 只有直接分配才看到
重复 refresh 不重复提醒
```

```text
secret
token
```
