## 5. 不直接清理开发库

已有 `DEV-DATA-CLEANUP-PLAN.md` 继续保留。

Pilot 推荐：

```text
新建空白 Pilot DB
```

而不是：

```text
cleanup_dev_data --execute
```

原因：

- 开发库存在无 `GATE` 前缀历史测试人员
- 仍有无 `GATE` 前缀费用
- 自动识别存在误删风险

因此：

> 清理开发库不是进入 Pilot 的必要前置。

## 11. 四角色权限验收

### ADMIN

```text
全部项目
全部资源
全部费用
导入
导出
提醒
审计
设置
```

### BOSS

```text
全局只读
无导入
设置只读
审计可查
无写按钮
```

### PROJECT_MANAGER

```text
只看到自己负责项目
只看到自己项目资源
只看到自己项目费用份额
只导出自己项目
无审计 / 设置
```

### MEMBER

```text
只看到自己参与项目
只看到直接分配给自己的资源
只看到直接分摊给自己的费用
只导出本人资源 / 费用
不能看到其他成员
```

- ADMIN/BOSS 全局

- refresh 幂等

```text

Import Commit
```

然后验证 Audit：

```text

time

action

```

```text

secret
token
```
