时间范围仍是本月、近3个月、近6个月、今年、自定义。切换到「今年」后，overview、expense-trend、project-costs、resource-type-costs、billing-costs 按 `date_from=2026-01-01` 重新请求。resource-status 与 expiring-resources 不带日期参数，状态语义没有被改成时间区间指标。

自定义 2020-01-01 至 2020-01-31：

- 本期费用：暂无费用
- 费用趋势：当前时间范围暂无费用数据
- 项目成本：当前时间范围暂无项目费用
- 费用结构：当前时间范围暂无费用数据
- 资源状态与需要关注仍显示当前资源事实

## Data Consistency

本月、BOSS Scope：

| 对照 | 结果 |
| --- | --- |
| 项目数 3 | `GET /api/projects` 的 total 为 3 |
| 活跃资源 11 | `overview.active_resource_count` 与 `resource-status.counts.ACTIVE` 都是 11 |
| 闲置 / 未分配 1 / 3 | overview 与 resource-status 一致 |
| 即将到期 1 | overview、resource-status `EXPIRING_SOON`、expiring-resources 条数都是 1 |
| 本期费用 | 经营总览与统计分析页都是 CNY 7,232.50、USD 100.00 |
| 项目成本 4 行 | 与 `project-costs` 返回行一致；统计分析「项目」Tab 相同 |
| 资源类型费用 | CNY 7,132.50 + 100.00 = 7,232.50，USD 100.00，与 overview 一致 |

项目成本四行的 CNY 合计低于 overview 的 CNY。`project-costs` 只汇总挂了项目的分摊，overview 汇总当前范围内的全部分摊。首页两块各自使用对应接口，没有再算一遍。
