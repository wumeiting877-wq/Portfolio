## Route Matrix

`meta.roles` 来自 `ROUTE_ROLES`。不允许的角色在 `beforeEach` 里重定向到 `home`，不新增 403 页。这是前端体验策略。Backend Scope 仍是安全边界。

| Route | Path | Roles |
| --- | --- | --- |
| home | `/` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| statistics | `/statistics` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| projects | `/projects` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| project-detail | `/projects/:id` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| resources | `/resources` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| resource-detail | `/resources/:id` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| expenses | `/expenses` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| expense-detail | `/expenses/:id` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| recurring-expenses | `/recurring-expenses` | ADMIN, BOSS |
| employees | `/employees` | ADMIN, BOSS |
| users | `/users` | ADMIN |
| import-export | `/import-export` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| notifications | `/notifications` | ADMIN, BOSS, PROJECT_MANAGER, MEMBER |
| audit-logs | `/audit-logs` | ADMIN, BOSS |
| settings | `/settings` | ADMIN |

开发环境账号 `admin` / `boss` / `pm` / `member` 实测：

| 账号 | 直接打开 | 结果 |
| --- | --- | --- |
| BOSS | `/users`、`/settings` | `/`，PageHeader 仍是经营总览。对应页面 chunk 未加载 |
| PROJECT_MANAGER | `/recurring-expenses`、`/employees`、`/users`、`/audit-logs`、`/settings` | `/`，PageHeader 仍是项目看板 |
| MEMBER | `/recurring-expenses`、`/employees`、`/users`、`/audit-logs`、`/settings` | `/`，PageHeader 仍是我的资源 |

BOSS 的 `canViewSettings` getter 仍表示后端可读设置。菜单不再用这个 getter 决定入口。直接访问 `/settings` 由前端 Route Guard 送回首页。后端 `canViewSettings` 语义未改。
