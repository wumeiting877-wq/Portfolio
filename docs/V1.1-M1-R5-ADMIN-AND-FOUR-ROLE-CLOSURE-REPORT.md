## 29. Accepted Gaps

```text
PROJECT_MANAGER project-filtered UNASSIGNED_ACTIVE
→ ACCEPTED SEMANTIC GAP
```

原因：Project scoped resources 要求存在该项目有效分配，而 `UNASSIGNED_ACTIVE` 要求不存在任何有效分配，两个谓词不能同时成立。现有 verify 脚本仅因此返回整体 FAIL；其他 Demo、Scope、币种、隔离与空态检查全部 PASS。此结果不是 R5 blocker。
